# Recording Disclaimer (MVP1)

Use of AI Admin Assistant recording features requires user responsibility for lawful and ethical recording.

## Required User Confirmation
Before starting a recording session, the user confirms:
1. Participants are informed recording is in progress.
2. Any required consent has been obtained.
3. Recording complies with employer policy, contract terms, and applicable laws.

## Privacy and Data Handling
1. Record only work-relevant content.
2. Avoid recording sensitive personal information unless explicitly required and approved.
3. Store recordings in secured folders.
4. Apply retention/deletion policies aligned with company policy.

## AI Output Limitation
1. Transcripts and generated tasks/emails are assistant drafts.
2. Human review is required before sending communications or taking actions.
